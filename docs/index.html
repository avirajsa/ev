EV Cloud Backend

An EDITH-inspired omnipresent AI Assistant core with real-time multi-device remote execution, resilient OpenRouter model failover, persistent vector memory, and Model Context Protocol (MCP) server integration.

Resilient LLM Failover

Automatically switches models (Claude ➔ GPT-4o ➔ Gemini ➔ Llama) if token limits, 429 rate limits, or outages occur.

Remote Device RPC

Full-duplex WebSocket hub connects Laptop daemons, Mobile voice apps, and IoT nodes for cross-device control.

Frictionless Astral uv

Blazing fast package management with sub-second dependency installation and zero-config virtualenvs.

Docker Compose Stack

Single command multi-stage container deployment with PostgreSQL (pgvector) and Redis cache backend.

Quick Start Guide (`uv`)

Get the EV Cloud Backend running locally in under 30 seconds using Astral `uv`:

# 1. Clone repository and copy environment config
cp .env.example .env

# 2. Create virtualenv & install dependencies in milliseconds
uv venv
uv pip install -e ".[dev]"

# 3. Start development server
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
# Developer shortcuts via Makefile
make install      # Create venv & install dependencies
make dev          # Run uvicorn server with auto-reload
make test         # Run pytest test suite
make docker-up    # Launch full Docker Compose stack

API Integration Snippets

Sample code snippets to query EV Agent and dispatch remote commands across connected devices:

import websockets, asyncio, json

async def connect_laptop_client():
    url = "ws://localhost:8000/ws/connect?token=ev_device_shared_secret_token_12345&device_id=my-laptop&device_name=MacBook&device_type=laptop&capabilities=[\"gui\",\"terminal\"]"
    async with websockets.connect(url) as ws:
        print("Registered with EV Network:", await ws.recv())
        while True:
            frame = json.loads(await ws.recv())
            if frame.get("type") == "rpc_request":
                # Execute local action and send response back to EV Cloud
                await ws.send(json.dumps({
                    "type": "rpc_response",
                    "request_id": frame["request_id"],
                    "status": "success",
                    "result": {"output": "Command executed on Laptop"}
                }))

asyncio.run(connect_laptop_client())
# Submit a request to EV Agent
curl -X POST http://localhost:8000/api/v1/agent/query \
  -H "Authorization: Bearer ev_device_shared_secret_token_12345" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "Open Spotify on my laptop",
    "preferred_model": "anthropic/claude-3.5-sonnet"
  }'
const ws = new WebSocket('ws://localhost:8000/ws/connect?token=ev_device_shared_secret_token_12345&device_id=phone-app&device_type=phone');

ws.onopen = () => console.log('Mobile Phone App connected to EV');
ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('Received event from EV Cloud:', data);
};
